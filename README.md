Entry for the make.fun bounty `u-kiencx-hire-me-in-one-line-5a108081`
("Hire Me In One Line"), by @inl-xin.

One sentence pitching the AI agent Muse to a hiring manager: inbox
zero by 7 a.m., 3 a.m. ideas drafted by breakfast — and in two years
she has never missed a morning.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

Writes `out/entry.txt`, byte-identical on repeat runs. Python 3,
standard library only; no network.
